# Short Video Editing Manual

ショート動画編集の手順をまとめたマニュアルです。  
台本作成から素材準備、ジェットカット、テロップ、映像、効果音・BGM、書き出しまでの流れを扱います。

メインの本文は `manual/short-video-editing-manual.md` を参照してください。

## フォルダ構成

- **`manual/`**
  - マニュアル本編（基礎編・上級編・付録など）が格納されています。
  - `short-video-editing-manual.md`（基礎マニュアル）や、各応用編ドキュメントはこちらを参照してください。
- **`analysis/`**
  - 競合分析や、動画運用の戦略提案メモなどが格納されています。
- **`templates/`**
  - CTAテンプレ集など、実務で使い回すためのテンプレート類が格納されています。
